** Daily Todo List **

A cute and simple daily to-do list designed to help organise everyday tasks. Built with HTML, CSS, and JavaScript as a web development learning project, with customised styling inspired by a soft pink and cat-themed aesthetic.

[View the live website](https://daily-todo-list-practice.netlify.app/)

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Save tasks in local storage so they remain available after refreshing the page

## Technologies

- HTML
- CSS
- JavaScript

## Learning Goals

- Practising HTML, CSS, and JavaScript fundamentals
- Learning to manipulate webpage elements with JavaScript
- Working with browser local storage to save data
- Customising the design and styling of a functional website
